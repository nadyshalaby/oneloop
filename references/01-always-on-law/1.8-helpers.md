# 1.8 [rule] Helpers

This section has no long form: its whole text is the core law's 1.8, in
`law/engineering-law.md`, which the user-global `CLAUDE.md` loads into every session: a helper
is sent only when it saves more than it costs, never a fork, always a named model, a short

session are the workflow skill's (Helpers). This file keeps the section number stable.
